# Equisoft's Design System
## Getting Started

#### Add the library to your project
`yarn add @equisoft/design-elements-react`

#### Add the DesignSystem provider to your app

Simply add the provider in your App component. It should be something like this:
```typescript jsx
import { DesignSystem } from '@equisoft/design-elements-react';
import { type FC } from 'react';
import { Router } from 'react-router';
import { Route, Switch } from 'react-router-dom';

export const App: FC = () => (
    <DesignSystem>
        <Router>
            <Switch>
                <Route component={HomeComponent} />
            </Switch>
        </Router>
    </DesignSystem>
);
```

## Theming

For most cases, you won't need to provide a theme, as the DesignSystem uses Equisoft's color scheme by default. However,
it's possible to override parts of the theme by providing a `themeCustomization` object to the `DesignSystem` component.
For more details, take a look at the [type definitions](https://github.com/kronostechnologies/design-elements/blob/master/packages/react/src/themes/theme.ts)
and the list of available design tokens.

## Internationalization

If your application supports multiple languages, you simply need to provide your application's configured language to
the `language` prop of the `DesignSystem` component. The default value is `en` (English). You can switch the language
throughout the Storybook using the globe icon in the toolbar.

The following sample shows that the provider only translates the messages
related to the design system. For a more complex example, take a look at the [webapp-boilerplate](https://github.com/kronostechnologies/webapp-boilerplate/tree/master/web/src/browser).
